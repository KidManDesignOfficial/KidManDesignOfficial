# PC Atölyesi 3D

Mobil uyumlu, animasyonlu 3D bilgisayar toplama oyunu. Tek dosya (`index.html`), kurulum gerektirmez.

- 8 adım: kasa, anakart, işlemci, soğutucu, bellek, ekran kartı, depolama, güç kaynağı
- Uyumluluk: soket (AM4/AM5/LGA1700/LGA1851), DDR4/DDR5, güç kaynağı yeterliliği, soğutucu kapasitesi
- Parçalar kasaya uçarak takılır; "Güç Ver" ile cam kapak kapanır, fanlar döner, RGB yanar
- 12 oyun için 1080p/1440p/4K ve Orta/Yüksek/Ultra FPS tahmini, 1% low, darboğaz, güç yükü, CPU sıcaklığı

Performans verileri Tom's Hardware 2026 GPU ve CPU hiyerarşilerinden türetilmiştir; sonuçlar tahminidir.

Çalıştırma: `index.html` dosyasını tarayıcıda aç (Three.js CDN'den yüklenir).
